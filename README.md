# Part Five

[언어 공부 시작하기](https://minkyukang707.github.io/part-five/)

시작 화면에서 영어·일본어·스페인어·터키어를 선택합니다. 선택한 언어의 학습 메뉴, 진도, 오답 분석과 몬스터 원정이 표시됩니다. 영어는 문법·오답 복습·3,000개 단어·Listening·Writing·내 자료로 공부를 제공하고, 다른 언어는 입문 문법과 단어 공부를 제공합니다. GPT나 API 키 없이 작동합니다.

개인 진도, 장비, 골드, 단어 학습 기록과 Writing 초안은 사용 중인 브라우저에 저장됩니다. 각 언어는 별도의 체력·몬스터 레벨·연속 정답·장비·골드를 사용합니다. 브라우저의 사이트 데이터를 지우면 개인 학습 기록도 삭제됩니다. 첫 방문 때 기본 학습 자료를 저장하고, Writing 검사기는 처음 피드백을 요청할 때 내려받습니다.

오른쪽 위 **캐릭터 설정**에서 이름과 남자·여자 기사를 고를 수 있습니다. 저장한 뒤에는 같은 위치의 이름을 눌러 다시 편집합니다. 캐릭터 변경은 장비와 전투 진도를 유지합니다. 게임·공부 진도 초기화도 이 설정 창에서 이용할 수 있습니다.

## 수정과 배포

### 학습 공간

- **문법 배우기**는 일본어·스페인어·터키어에서 제공합니다. A1–C2별 12강씩, **언어별 72강·총 216강**입니다. 의미와 용도, 문장 구성 순서, 헷갈리는 표현과 주의점, 수업별 3개 이상의 번역·구조 풀이 예문을 읽고 연습합니다. TUFS·국제교류기금·Cervantes·RAE·Yunus Emre 등 외부 교육 자료를 참고했으며 각 수업에 참고 링크가 있습니다. 단계는 앱의 자체 편성이며 공식 시험 전체 범위나 수준 인증을 뜻하지 않습니다.
- **문법 문장 연습**은 언어별 240문항, 총 720문항입니다. 수업별 새 문장 3개와 기존 수업의 확인 문제를 포함합니다. 보기 순서를 섞고 적게 풀었던 문장을 우선 제공합니다. 새 수업은 서로 다른 문장 2개를 맞히면 완료됩니다. 오답 문법은 바로 전과 다른 문장으로 다시 풀고, 오답 후 서로 다른 문장 2개를 맞히면 복습 목록에서 빠집니다. 화면의 ‘오답 문법만 보기’·‘다음 오답 문법 복습’과 성장 대시보드에서 연결됩니다.
- 문법 진도·오답·진행 중인 문제와 보기 순서는 언어별로 저장되며, 이전 버전의 24강 완료 기록도 유지됩니다. 공부 모드이므로 문법 연습으로 전투·골드는 변하지 않습니다. 예문은 앱을 위해 작성한 고정 문제은행이며 무한한 신규 생성이나 공식 능력 인증을 제공하는 과정은 아닙니다.
- **단어 공부**는 네 언어 모두 `8초 동안 뜻 익히기 → 뜻을 가린 한국어 입력 퀴즈 → 해설` 순서입니다. ‘천천히 읽기’로 학습 시간을 멈출 수 있고, 다른 화면·탭에서는 시간이 줄지 않습니다. 학습 중에는 채점되지 않으며 퀴즈 제출 때만 기존 진도를 갱신합니다.
- **일본어 읽기**는 2,000단어의 가나 읽기와 한국어 근사 발음을 제공합니다. 히라가나·가타카나 표, 탁음·반탁음, 요음·촉음·장음·조사 읽기 안내도 포함합니다. 한국어 표기는 보조 수단이며 높낮이까지 재현하지 않습니다. 읽기 출처와 재생성 방법은 [JMdict 자료 고지](site/notices/japanese-readings.txt)를 확인하세요.
- **기억의 정원**은 전체 카드 미리보기 약 8초와 부드러운 뒤집기 이후 제한시간을 시작합니다. 미리보기 중에는 답을 선택할 수 없고 게임 시간이 줄지 않습니다. 화면 이탈·일시정지와 운영체제의 동작 줄이기 설정을 지원합니다.

- **나의 성장**에서 선택한 언어의 날짜별 학습량, 문법 유형·개별 단어의 오답 횟수, 복습 우선순위와 원정 진척도를 확인합니다. 누적 기록과 오답 목록에는 이전 학습도 반영하며, 언어별 날짜 그래프는 언어 분리 업데이트 이후부터 집계합니다. 현재 언어·단계의 최근 20문항에서 정답률 85% 이상이면 상향, 50% 미만이면 하향을 제안합니다. 사용자가 버튼을 누를 때 단계가 바뀝니다.
- **내 자료로 공부**는 PDF·TXT·MD 파일과 붙여 넣은 본문을 기기에서 읽어 원문 표현 복원 문제를 만듭니다. 영어·일본어·스페인어·터키어를 선택할 수 있습니다. 텍스트 PDF를 지원하며 이미지로만 된 스캔 PDF는 OCR로 글자를 추출한 뒤 넣어야 합니다. 파일당 20 MB·200쪽·60만 자 이내, 자료 최대 30개입니다.
- **Listening**은 Josh Woodward 공식 채널에서 Creative Commons Attribution 이용을 허용한 노래 3곡의 첫 절 12구절로 시작합니다. 공식 YouTube 플레이어를 열어 듣고 직접 받아씁니다. 구간 시작·끝은 듣고 설정할 수 있습니다. 채널 설명에 고지된 라이선스와 출처는 화면 및 [Listening 자료 고지](site/notices/listening-sources.txt)에 표시합니다.
- **외국어 개인 학습**은 일본어 1,971문항, 스페인어 2,252문항, 터키어 2,437문항과 **각 언어 2,000개 단어**를 제공합니다. 일상·여행·학교·운동·음식/쇼핑·직장/사회·건강/자연·문화/취미의 8개 주제와 기타 표현을 선택할 수 있습니다. 아직 풀지 않은 문장과 다른 유형을 우선 출제하며, 단어는 30개씩 67세트(마지막 20개)로 한국어 뜻을 입력해 공부합니다. 기존 문제와 유지되는 단어의 ID는 보존하며 교체된 단어의 학습 횟수는 누적 기록에 보관합니다.
- 기존 자체 문법 48문항에 Tatoeba/ManyThings 공개 예문을 활용한 **원문 표현 복원** 연습을 더했습니다. 추가 예문 6,516문항에 **한국어 의미 힌트**, 한국어 형태 학습 설명과 개별 출처를 표시합니다. 힌트는 개발 과정에서 로컬 OPUS-MT 번역기로 미리 생성하고 관용어·부정·누락·깨진 문자 등을 검사해 일부를 직접 교정했습니다. 공부할 때 GPT나 번역 API를 호출하지 않습니다. 다른 표현도 문법적으로 가능한 원문 복원형이며, 번역·자동 분류 오류가 남을 수 있습니다.
- **단어 뜻 검토**는 기존 6,000개 항목을 한국어 위키낱말사전 자료와 전수 대조했습니다. 직접 한국어 뜻을 확보하지 못한 자동 연결 항목은 사전 근거가 있는 단어로 교체하고, 기초 60개/언어와 명시적 뜻 교정은 보존했습니다. 단어 피드백에서 자료 출처를 확인합니다. 교체된 단어의 학습 횟수는 누적 기록에 보관하고, 새 단어를 이미 외운 것으로 처리하지 않습니다. [검토 내역](site/notices/vocabulary-review.json)과 [출처·재생성 안내](site/notices/language-expansion.txt)를 제공합니다. 사전 대조·자동 검사·표본 편집 교정이며 원어민 전수 감수는 아닙니다. PvP 서버의 별도 기초 문제은행은 이번 개인 학습 확장과 구분됩니다.
- **미니게임**은 네 언어에서 카드 짝맞추기 ‘기억의 정원’, 단어 5개를 만드는 ‘글자 공방’, 제한시간 안에 뜻을 고르는 ‘별빛 캐치’, 7×7 글자판에서 단어를 찾는 ‘단어 탐험’을 제공합니다. 현재 언어의 단어장을 사용하며 게임별 최고 점수·별·완료 횟수를 언어·난이도별로 저장합니다. 난이도 도입 전 기록은 별도 표시하여 보존합니다. 몬스터 전투·학습 정답률과 별도로 기록합니다. 한 판 완료 시 `floor(점수 / 20 × 난이도 배율)` G를 해당 언어의 상점 잔액에 지급하며, 완료 화면을 다시 열어도 중복 지급하지 않습니다. 단어 공부와 미니게임의 오답에 따라 출제 가중치를 최대 6으로 높입니다. 글자 조립은 마지막 글자에서 자동 채점하고 정답은 0.45초 후 다음 문제로, 오답은 붉은 강조와 정답을 1.4초 표시한 뒤 이어집니다. 상점에는 구매할 무기와 방어구의 그림이 표시됩니다. 시간제한 게임은 탭을 숨기거나 다른 메뉴로 이동하면 멈추고 재개 버튼으로 이어갑니다. 진도 초기화에 미니게임 기록도 포함됩니다.

미니게임 단계는 입문·쉬움·보통·어려움·도전입니다. 선택은 언어별 저장되며 게임 중 변경할 수 없습니다. 카드·탐험은 한 판 전체, 조립·별빛은 문제별 제한시간입니다. 카드·탐험 시간 초과 시 찾지 못한 단어를 복습 기록에 남기고 현재 점수만 정산합니다. 조립 시간 초과는 오답으로 다음 문제, 별빛은 기회 1회 차감으로 처리합니다. 중도 나가기에는 보상이 없습니다.

| 단계 | 카드/판 | 조립/문제 | 별빛/문제 | 탐험/판 | 보상 배율 |
|---|---:|---:|---:|---:|---:|
| 1 입문 | 150초 | 30초 | 15초 | 180초 | 1 |
| 2 쉬움 | 120초 | 25초 | 12초 | 150초 | 1.25 |
| 3 보통 | 100초 | 20초 | 10초 | 120초 | 1.5 |
| 4 어려움 | 80초 | 16초 | 8초 | 90초 | 2 |
| 5 도전 | 60초 | 12초 | 6초 | 60초 | 3 |

단어 단계는 자체 기초 단어, 기존 수집 Tatoeba/ManyThings 예문 전체의 단어 등장 빈도, 표기 길이를 조합한 상대 난이도입니다. CEFR·JLPT 등 공식 등급은 아닙니다. 낮은 단계는 빈도가 높은 기초 표현, 높은 단계는 드물거나 복잡한 표현을 중심으로 구성합니다. 선택한 단계의 단어만 사용하며 게임 규칙에 맞는 길이를 필터링한 뒤 오답 가중치를 적용합니다. 일본어 단어 경계는 `Intl.Segmenter`, 터키어 대소문자는 해당 언어 규칙을 사용합니다. 재생성: `node scripts/build-minigame-levels.cjs` (저장된 `scripts/minigame-word-frequency.json` 사용). 전체 예문 입력을 갱신할 때는 같은 명령에 언어별 문장 배열 JSON 경로를 인수로 전달합니다.

- 상단에서 **다크·라이트**를 전환하며 선택은 저장됩니다. 몬스터마다 달라지는 40개 배경, 호흡·공격·피격 효과를 지원합니다. 추가된 20종은 파리·교토·페트라·마추픽추 등 세계 명소를 참고해 제작했습니다. 운영체제의 동작 줄이기 설정을 따릅니다.
- **PvP · 리더보드**는 선택한 언어의 문법과 단어를 섞어 90초 동안 겨룹니다. 초대 코드로 두 사람이 참가하며 같은 순서의 문제를 풉니다. 정답마다 10점이며 정답 수가 많으면 승리, 같으면 무승부입니다. 순위는 언어별 승수·최고 점수·누적 정답 순으로 정합니다. 연결과 경기 기록의 저장 방식은 [경쟁 서버 안내](competition-server/README.md)에 있습니다.

### 개발

학습 화면과 데이터는 `site/`, 문장 수집기와 정적 사이트 빌드는 `scripts/`, PvP 서버 코드는 `competition-server/`에 있습니다. Node.js 24 이상에서 다음 명령으로 확인할 수 있습니다.

```sh
node scripts/check.cjs
node --test competition-server/arena.test.mjs
node scripts/build.cjs
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000/`을 엽니다. `main`에 푸시하면 GitHub Actions에서 검증과 Pages 배포를 수행합니다. 저장소의 **Settings → Pages → Source**는 **GitHub Actions**입니다.

외국어 확장 자료를 다시 만들려면 출처 고지에 연결된 원본 ZIP을 한 폴더에 `extended.zip`, `jpn.zip`, `spa.zip`, `tur.zip`으로 저장하고 `python scripts/build-language-expansion.py <그 폴더 경로>`를 실행합니다. Python 3와 Node.js 24가 필요하며 외부 패키지나 GPT를 사용하지 않습니다. 기본 뜻 보정은 `scripts/language-meaning-overrides.json`에서 관리합니다. 생성된 자료가 저장소에 포함되어 있어 일반 빌드·배포에는 재수집이 필요하지 않습니다.

## 온라인 문제

GitHub Actions가 매일 Europe PMC 공개 논문, NASA 뉴스, Tatoeba/ManyThings 문장 자료를 확인합니다. Tatoeba 언어 팩은 매일 돌아가면서 처리합니다. 새 문제는 출처를 붙이고 중복을 제거해 누적합니다. 방문자는 **새 문장 받기**로 최신 문제를 내려받을 수 있습니다. 자동 받기가 켜져 있으면 사이트를 열 때도 갱신합니다.

즉시 갱신하려면 **Actions → Part Five Pages → Run workflow**에서 **Refresh the sentence library**를 선택합니다. 자료별 출처와 라이선스는 [학습 자료 고지](site/notices/learning-data.txt)에 수록했습니다.


### 확장 장비 상점

무기와 방어구는 기본 지급 장비를 포함해 각각 10종입니다. 기존 0~5단계 장비의 가격·능력치·저장 기록을 유지하고, 각 종류에 다음 4단계를 추가했습니다. 해당 종류의 이전 단계를 구매한 뒤 순서대로 구입합니다.

| 단계 | 무기 / 방어구 | 각 가격 | 무기 공격력 보너스 | 방어구 최대 HP 보너스 |
|---|---|---:|---:|---:|
| 6 | 홍련 대검 / 홍련 갑주 | 1,250 G | +62 | +340 |
| 7 | 월식도 / 월식 갑주 | 2,400 G | +88 | +470 |
| 8 | 천공의 창 / 천공 갑주 | 4,500 G | +120 | +630 |
| 9 | 태양왕의 검 / 태양왕의 갑주 | 8,000 G | +160 | +820 |

능력치는 최고 구매 단계의 보너스입니다(단계별 보너스를 더하는 방식이 아님). 무기는 기본 공격 10에 보너스를 더하고, 방어구는 기본 체력 100과 몬스터 처치당 +10에 보너스를 더합니다. 구매 즉시 장착되며, 살아 있을 때 방어구 구매로 늘어난 최대 체력만큼 현재 체력도 증가합니다. 쓰러진 상태에서는 재도전이 필요합니다.

상점에서 전체 단계의 가격·능력치·그림을 비교하고, 착용 중인 조합을 미리 볼 수 있습니다. 이미 보유한 장비는 무료로 외형만 바꿀 수 있으며 최고 능력치와 골드는 유지됩니다. 외형 선택도 언어별로 저장합니다. 전투 캐릭터·캐릭터 설정 미리보기·상점에 같은 장비 그림을 사용합니다.

캐릭터는 원래의 48×44 남녀 픽셀 원본을 사용합니다. 기존 장비 0~5단계는 원본 그대로, 추가 장비 6~9단계는 동일한 좌표와 색상 스타일로 그린 픽셀 레이어를 사용합니다. 상점 아이콘은 각각 32×32로 제작해 `image-rendering: pixelated`로 표시합니다. 실제 사람처럼 보이는 캐릭터 및 사실적인 장비 이미지는 서비스 자산에서 제거했습니다. 장비 종류·능력치·가격·보유 기록과 외형 변경 기능은 유지합니다.

추가 픽셀 자산 재생성: `node scripts/build-pixel-gear.cjs`. 출력은 `site/arena/pixel-gear/`입니다. 원래 픽셀 캐릭터와 장비 제작 코드를 확장한 방식으로, 이미지 생성 API는 사용하지 않습니다.
